## 📝 Documentation Philosophy

This repository uses a three-level documentation hierarchy:

- **Level 1 — Repository README**: Explains what the repository is and provides the overall learning map.
- **Level 2 — Topic README**: Documents what I learned throughout an entire curriculum topic.
- **Level 3 — Exercise README**: Documents what I actually did and learned in a specific exercise.

Documentation follows the ASD-STE100 Simplified Technical English standard for clarity and consistency.
