## Strings

### String Interpolation

Use $"..." syntax to combine text and variables.
Example: $"Hello, {name}!" inserts the value of the name variable.

### String Methods

- .ToUpper() - Converts text to uppercase
- .ToLower() - Converts text to lowercase
- .Replace() - Replaces specific characters or substrings

### Escape Characters

- \n - Newline
- \t - Tab

### String Literals

Text must be enclosed in double quotes ("").

## Console I/O

### Console Output

- Console.WriteLine() - Prints text and adds a line break
- Console.Write() - Prints text without adding a line break

### User Input

- Console.ReadLine() - Pauses program and waits for user input, always returns a string

### Syntax Rules

- All C# statements must end with a semicolon (;)
- Comments are ignored during execution
